# Module 6 Submission Checklist

## Deliverable A - Project portfolio

- [ ] Public GitHub repository link tested in a signed-out/private browser window.
- [ ] Source code, updated notebook, README, sample CSV and documentation included.
- [ ] Trusted trained model artifact and matching SHA-256 checksum published as a release asset or included in the repository.
- [ ] Streamlit app deployed and tested by an unauthenticated reviewer, or explain that only local execution is available.
- [ ] No API keys, passwords, credentials, private traffic captures or secrets committed.
- [ ] Group contribution table completed and reviewed.

## Deliverable B - Capstone video

- [ ] Screen-recorded presentation is no longer than 10 minutes and 250 MB.
- [ ] Shows actual application input and actual model output, once the model artifact is present.
- [ ] Explains dataset, pipeline, evaluation, deployment and maintenance.
- [ ] Explicitly reports the independent-test generalization gap and poor R2L/U2R recall.
- [ ] Each group member explains their contribution.

## Deliverable C - One-page retrospective

- [ ] One-page retrospective included as DOCX/PDF.
- [ ] Achievements, challenges, lessons, limitations and improvements covered.

## Deliverable D - Data statement

- [ ] States that NSL-KDD is public benchmark data, not live operational traffic.
- [ ] Identifies the illustrative sample CSV.
- [ ] Discloses that SMOTENC synthesizes minority training examples only.

## Final accuracy check

- [ ] Do not present validation results as independent-test results.
- [ ] Do not state that all performance targets passed; all five failed on KDDTest+.
- [ ] Distinguish implemented features from proposed deployment/monitoring processes.
- [ ] Cite the benchmark source and verify dataset redistribution terms.
