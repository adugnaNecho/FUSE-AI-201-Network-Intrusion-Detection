# Group 19 NIDS Analytics Dashboard Guide

**Hosted app:** https://group19-network-intrusion-detection.streamlit.app/  
**Repository:** https://github.com/adugnaNecho/Group19-network-intrusion-detection

## Dashboard sections

The Streamlit app has three tabs: **CSV Prediction**, **Analytics Dashboard**, and **About & Limitations**.

### Benchmark model performance

The dashboard reads `artifacts/evaluation.json` generated by `train_model.py`. It displays accuracy, macro precision, macro recall and Macro F1; per-class metrics; the measured 5 × 5 confusion matrix; and one-versus-rest FPR when these values are present. The validation/test comparison is a grouped (side-by-side) bar chart with a 0–100% axis, not a stacked chart. Class order is Normal, DoS, Probe, U2R, R2L. Support values are integers; FPR displays use percentage formatting.

If the evaluation file is unavailable or invalid, the app uses only the disclosed run snapshot of aggregate metrics and class recall. It does not invent a confusion matrix, class precision/F1, or FPR values. If Plotly cannot render the FPR chart, the app displays the measured FPR table as a fallback rather than allowing the optional chart to crash the dashboard.

### Uploaded-record analytics

After uploading a 41-feature CSV and selecting **Predict intrusion class**, the dashboard summarizes current predictions: predicted class counts, severity counts, source/destination byte and count features, Normal-versus-predicted-attack profile, maximum class probability per record, and downloadable predictions.

The record-profile plots use record order, not time, because NSL-KDD's 41-feature schema has no timestamp. Source/destination byte values are displayed with `log10(value + 1)` for readability; model inputs and predictions are unchanged. The displayed maximum class probability is not claimed to be calibrated.

## Reproducible setup

```bash
python -m pip install -r requirements.txt
python -m pip install -r requirements-dev.txt
python -m pytest -q
streamlit run app.py
```

The model pipeline and supporting artifacts are maintained in the public GitHub repository under `artifacts/`. Use only the trusted artifact produced by the group's training script; joblib/pickle files should not be loaded from an untrusted source.

## Evaluation and limitations

Latest independent KDDTest+ results: accuracy 74.62%, macro precision 79.35%, macro recall 48.71%, Macro F1 51.51%. Class recall: Normal 97.28%, DoS 76.57%, Probe 53.52%, U2R 8.96%, R2L 7.20%. This is a benchmark-based research prototype for uploaded NSL-KDD-style connection records. It does not capture live packets, block traffic, or operate a production monitoring service.
